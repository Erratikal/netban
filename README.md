# netban endgame setup

Live site: https://netban.uk

Repo is public. Pages is already on from `main` / root. Domain is in `CNAME`.

## Edit later

1. Open https://github.com/Erratikal/netban
2. Click `index.html` for text, `styles.css` for look
3. Pencil, change it, commit

The site updates about a minute after the commit.

Gear lists are the `<ul>` blocks in `index.html`.

## HTTPS

Settings → Pages → custom domain `netban.uk` → wait for the certificate → tick Enforce HTTPS.
GitHub issues the cert. Do not add one in Spaceship.

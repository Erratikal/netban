# netban endgame setup

Live domain: [netban.uk](https://netban.uk)

Registrar: Spaceship. Keep those nameservers (`launch1.spaceship.net` / `launch2.spaceship.net`) and only edit DNS records.

## Edit later

1. Open [github.com/Erratikal/netban](https://github.com/Erratikal/netban)
2. Click any file (`index.html` for text, `styles.css` for look)
3. Click the pencil, change it, commit

Live site updates in about a minute after you save.

Gear lists live in `index.html` inside the `<ul>` blocks.

## Enable GitHub Pages (one-time)

Repo → **Settings** → **Pages** → Source **Deploy from a branch** → Branch **main** / **/(root)** → Save.

URL: `https://erratikal.github.io/netban/`

Optional custom domain: same Pages screen → Custom domain.
